# Kudzoka

Kudzoka is a modern, responsive landing page for a logistics and delivery service company. It provides users with an overview of the services offered, such as super-fast delivery, real-time tracking, volume-based discounts, and round-the-clock support.

**[🔴 Live Demo](https://kudzoka-two-gamma.vercel.app)**

## 🚀 Features

- **Responsive Design**: Adapts seamlessly to different screen sizes.
- **Modern UI/UX**: Clean aesthetic with dynamic CSS styling, hover effects, and smooth transitions.
- **Icon Integrations**: Utilizes FontAwesome and Boxicons for scalable and customizable vector icons.
- **Service Highlights**: Sections dedicated to showcasing core offerings and delivery statistics.
- **App Store Links**: Quick links to download the Kudzoka mobile application on the Apple App Store and Google Play Store.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for structure.
- **CSS3**: Custom styling, layout management (Flexbox/Grid), and animations.
- **FontAwesome & Boxicons**: For scalable vector icons used throughout the page.

## 📁 Project Structure

```
├── images/             # Directory containing all graphical assets and icons
├── index.html          # Main entry point and structural markup of the landing page
├── style.css           # Contains all styling, layouts, and animations
└── README.md           # Project documentation
```

## 💻 Getting Started

To view the project locally, you don't need any special server setup or build tools.

1. **Clone the repository** (if applicable) or download the source code.
2. Navigate to the project directory:
   ```bash
   cd Kudzoka
   ```
3. Open `index.html` in your preferred web browser.

## 🎨 Design Highlights

- The project uses a custom color palette with a prominent brand color (`#6C3F7E`) to highlight key elements and text.
